# Prompt 18 staged end-to-end marketing pilot execution plan

Status: PREPARED, NOT EXECUTED. Date: 2026-10-20.
Baseline: public AOS-W v0.7.0 portable preview and 21 independent marketing modules plus one compound lifecycle.

## Test case

A sanitized Bucket 9 inspired research-to-campaign planning case for a fictional seller of AI-assisted Meta advertising education and templates. Candidate buyers: coaches and consultants, independent agency owners and remodeling contractors. These labels are scenario scopes, not unsupported assertions of comparative opportunity scores, observed competitor ads, Meta Ads Library results or approved seller delivery claims.

The pilot deliberately uses fictional competitors and nonproduction evidence when live public evidence cannot be reliably accessed. A real-world T01 PASS additionally requires independently recorded and dated accessible public-source evidence. Mock evidence must never be upgraded to real research evidence.

## Execution boundaries

Do not change Meta Ads Manager, GHL, websites or external campaigns. Do not publish, deploy, spend or send messages. Final publishing step is a human authorization BLOCKED gate. Image output requires an actually generated and inspected asset; a creative brief or placeholder image does not constitute production.

## Required execution sequence

1. Install a clean 0.7.0 ZIP in a new directory. Verify SHA-256, no Git required and protected files unchanged.
2. Initialize the pinned compound marketing lifecycle and planning/keyword modules. Record run IDs, exact template hashes, four-field actor identity and CREATED events.
3. Approve only a bounded planning and research scope. Generate three deterministic child proposals for the candidate buyer groups, with unique IDs, source requirements and explicit review contracts.
4. Execute at least two real bounded research branches if public sources accessible. Record URLs, observation dates, evidence confidence and UNKNOWN or BLOCKED cases honestly. A fully synthetic branch remains labeled MOCK.
5. Insert an intentionally incomplete research artifact. Record an independent REVISE verdict on its exact digest, show downstream synthesis blocked while an unrelated branch remains ready, correct only the failed artifact, and retain both verdicts.
6. Reconcile and merge only exact-hash accepted child evidence. Separate observed competitor claims from seller offer hypotheses. Do not declare deliverability verified without actual owner and capability evidence.
7. Produce proposed positioning, primary text, headline, creative brief and an image asset if image-generation and visual inspection capabilities are actually available. Introduce a deliberate creative problem, have a distinct reviewing agent mark REVISE, repair just the asset, and keep previous hashes/reviews.
8. Create nonproduction paused-stage Meta campaign specification with targeting, exclusions, budgets, creative version pointers, tracking and a read-back plan. Prepare separate CRM and landing page branches and required integration gate, retaining UNKNOWN for untested provider operations.
9. Record final human launch permission as NOT_GRANTED and final campaign state as NOT_PUBLISHED. An accepted marketing plan does not convey authority to activate external systems.
10. Interrupt and cold-resume at least one active child from persisted files. Test a targeted graph revision with old outputs preserved. Record provenance, retries, reviews, handoffs and checkpoints.
11. Compare manual process overhead to earlier sessions with actual measured figures or report NOT_MEASURED. Run full regression and save logs and artifact digests.

## Evidence and definition of done

Persist sanitized run instance directories and event histories under tests/acceptance/evidence/p18 or an equivalent dedicated evidence location. Write docs/testing/PROMPT-18-PILOT-REPORT.md with expected versus observed results, execution environment, exact branch and template revisions, source evidence quality, hash references, gate attempts, branch merging and limitations. Record a verified commit and CI run when available.

Required cases: research incomplete then corrected, creative review fails then repaired, parallel branch independence, reviewed join, cold resume, immutable history, no-live-action permit denial, correct marketing truth labels and protected scaffold bytes unchanged.

If different AI providers, actual image generation, true public-source research or cloud storage are unavailable, mark those checks BLOCKED or NOT_RUN instead of creating passing simulations. This plan is NOT acceptance evidence and does not satisfy T01.
