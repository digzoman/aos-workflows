## Workflow issues and corrections

- Previous synthetic pilot had three research tasks inside one parent graph, not truly separate independently checkpointed child runs. Corrected with three separate durable instances in this pilot.
- Initial source-grounded pilot replaced rejected outputs without retaining original bytes. Corrected and rerun, preserving failed research JSON and failed PNG in durable versioned artifacts.
- A parent synthesis step can appear READY in the generic local state helper once its own graph predecessors complete even if external child-run review is incomplete. The pilot now makes a separate all-reviewed, exact-hash join check before synthesis. Generalizing fail-closed cross-instance join enforcement remains a framework backlog item.
- Initial audience evaluation was a reference-only synthesis. Replaced with substantive source-grounded positioning comparison and explicit confidence limits.
- The public-source evaluation is not the complete historically approved seven-weight criterion portfolio scorecard. The full B9 15-audience scoring cannot be inferred from only eight public offering pages and is not recalculated here.
- Initial research summary generated literal backslash-n sequences; the final pilot run corrected Markdown formatting. Earlier run evidence remains untouched.
