# Static compound research portfolio (0.2.0)

Shows a parent planner composed with three independently reusable, **version-and-SHA256-pinned** competitor investigation definitions for business coaches, agency owners and roofing contractors. Each child has explicit parameter bindings, predecessor approval and an `all_accepted` join. The common child template remains a separately reusable master.

The static `composition.children` list is an illustrative **definition**, not three live/generated runs. An agent creating these child runs must still check owner scope and use the same file-native instantiation contract as dynamic portfolio planning. The `composition.join` section declares that all three need current passing independent reviews before synthesis.

This template is purposefully non-repeating, does not grant external Meta permissions, and cannot by itself execute any children. See `../../references/COMPOSITION.md`.
