# AOS-W v0.9 — Capability recovery without unnecessary deferral

**Normative portable protocol.** A capable agent should act with initiative and make progress. A declared capability is an optimization aid, not a permission to complain, hand routine work back to a human, or abandon the run. This adds **zero new human approval gates**.

## Before saying a task is impossible

1. Read the pinned graph and actual persisted run. Check which permissions are truly required; do not invent approvals not defined there.
2. Inventory what the host can actually do: connected tools, browser, available repository and source files, approved skills, callable APIs, images and file operations. Test reasonable available routes instead of relying on names or generic model disclaimers.
3. Use the most direct authorized tool. If that fails, pursue supported equivalent methods (browser vs API vs saved evidence, or another already connected capable service). Try an independently callable reviewer when independent review is genuinely required. Do not pretend the same agent has independent reviewer status just because it used a different label.
4. If a live source cannot be reached, proceed with dated, accurately labeled research already stored in the run and prepare everything unaffected; do not claim you verified current ads that you did not.
5. Keep working on independent tasks, drafts, diagnostics and quality improvements. Missing one capability never blocks unrelated nodes.
6. Escalate ONLY the specific unmet invariant after a substantive attempt. Record exact attempted tools/sources, outcomes and narrow safe next step. Ask the owner for credentials or policy only when necessary and never invent a new human checkpoint as the answer to a routine tool problem.

## What cannot be waived

Real provider write/readback, evidence quality, pixel inspection if required, independent-review identity, source truth, existing human stage/spend/launch approval, privacy/security, and any owner-protected gate cannot be faked. A narrow blocked step is compatible with substantial continued work elsewhere.

## Workflow and visualization example

If "Ads Gallery" does not open, use approved browser navigation, official Meta Ad Library if that matches the task, permitted competitor evidence logs and historical records; verify the distinction between separate services. Produce a dated research record, mark live observations unverified where appropriate, and advance safe side work. The manager-facing visualization can say "Review updated ads evidence" or "Review requires fresh ad data", and describe attempts—never "Agent has no capabilities, ask a human" as the first action.

If an image-review tool is absent by its declared name, inspect whether the host supports native image vision, another connected image-capable model, local pixel checks or safe file preview. Record which checks genuinely ran and do not invent approval from unexamined pixels.

When external independent QC is essential, use an available authorized independent model/harness and retry alternate mechanisms before holding that QC node. Research corrections, safe copy drafts, static layouts, and other independent lanes must continue.
