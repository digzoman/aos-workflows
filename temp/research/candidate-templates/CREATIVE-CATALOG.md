## Common field contract, proposed

Each template must eventually specify stable task ID, human-readable role, source evidence pointers, required just-in-time skills, exact inputs and output files, deterministic acceptance checks where possible, AI visual/semantic review method, default permission scope, reviewer identity requirement, retry budget/route, per-artifact state, and prerequisites. Source versions and rubric revisions must be pinned per run.

### C03 semantic and claims are a production hard dependency

For source replication, preserve source buyer/trigger/hook/mechanism/offer/outcome/commercial path. Original brief requires Tier A source anchors on the complete package and at least two on-image, unless explicitly removed. A preimage failure cannot be cured by declaring the final PNG attractive. Unsupported competitor success claims, logos, customer references or exclusive product features must not be adopted.

### C08 is placement-aware, not one blind square transform

A new square size/blur technique can solve cropping but also harm visual hierarchy. Require intended Meta placement or approved generic target plus format-specific inspector. Any 9:16 placement remains pending until previewed or separately designed.

### C13 approvals are granular

The owner can select a logo-free version or one among three B8 variants; only that specific selection and approved alternate set advance. Human approval of creative assets alone does not authorize staging, live publishing, spending, chatbot changes or unrelated adsets.

## Research-derived first V1 test recommendation

Start with one sanitized B6.1-like source adaptation and two assets (imagery/no imagery), add a deliberate wrong-logo correction, a portrait-to-square format repair, a peer QC fail/pass and an owner-approval gate. Then optionally test a B8-style three-variant staging package using mocked provider links. No live ad account actions in this acceptance experiment.
